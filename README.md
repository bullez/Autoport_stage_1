# Автопорт-Групп — Первый этап

Статическая страница с итогами первого этапа: книга бренда, шрифт, логотип, иконки,
палитра и варианты фотографий на выбор.

## Что внутри

```
index.html                 — вся страница, один файл
assets/
  bb-avtoport-v3.pdf       — книга бренда, версия 3 (50 страниц)
  pages/p01…p50.webp       — превью страниц
  fonts/                   — Avtoport Regular (исправленный) и Italic, для @font-face и скачивания
  img/logo/                — 11 версий логотипа и знака, PNG с прозрачностью
  img/icons/               — 15 иконок, синяя версия
  img/memo/                — ПАМЯТКА (логотип) и СПРАВКА (знаки)
  img/spec/                — таблицы начертаний и полный набор символов
  img/photos/              — 61 кадр-вариант по страницам 46, 47, 48
```

## Просмотр

Книга и фотографии открываются внутри страницы, без новых вкладок:

- клик по странице книги — открывается крупно, листается стрелками, клавишами
  ← → и свайпом (мышью или пальцем);
- клик по фото — открывается на весь экран в пределах своей сцены;
- закрыть: крестик, Esc или клик по тёмному фону.

## Шрифт

В исходном `Avtoport.ttf` у части глифов (Й, Ы, Б, В, Ю) внешние контуры были нарисованы
в разные стороны: на стыке двух фигур встречались +1 и −1, сумма давала ноль, и появлялся
белый шов. На крупном кегле это читалось как брак буквы.

В папке лежит исправленная версия: внешние контуры приведены к одному направлению,
дырки — к противоположному. Счётчики (О, Б, В, Р, Ю, Ь) при этом сохранены.

Исправленные файлы для установки: `Avtoport-fix2.ttf` и `Avtoport-fix2.otf` в рабочей папке
проекта (`avtoport/шрифт`). В книге на страницах 26 и 38 стоит старый файл — его надо заменить
через Type → Find Font, иначе швы уйдут в печать.

## Как опубликовать на GitHub Pages

1. Создать репозиторий, например `avtoport-etap-1`.
2. Загрузить **содержимое папки** `этап-1` в корень репозитория (чтобы `index.html` лежал в корне).
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, папка `/ (root)`.
4. Через минуту страница: `https://<username>.github.io/avtoport-etap-1/`.

Проверить локально можно двойным кликом по `index.html` — всё работает без сервера.

## Замечания по содержанию

- На фото стоит только метка «рекомендую» — без оценок «не брать» и без технических
  замечаний: страница клиентская. Внутренние пометки хранятся в генераторе
  (`PICKS`, `NOTES`), в HTML они не попадают.
- Правки вносить лучше в генератор `avtoport/build_site.py` и пересобирать. Ручная правка
  `index.html` допустима, но при пересборке пропадёт.
- Общий вес папки ≈ 25 МБ, из них 17 МБ — PDF книги.
